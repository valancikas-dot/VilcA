📋 How to Manage Task List

Learn how to effectively plan tasks, assign workers, and track project progress.

1

Create Task List

In project, go to "Tasks" section. Create tasks: "Install drywall", "Prime walls", "Lay flooring", etc.

2

Set Priorities and Deadlines

For each task, set priority (urgent/regular) and deadline. You'll see which tasks are most important.

3

Assign Workers

Assign each task to a worker. They'll receive notification and see their task in their app.

4

Track Progress

Workers update task status: "In progress", "Waiting for materials", "Completed". You see real-time progress.

5

Analyze and Plan

See which tasks are delayed, where the issues are. Plan upcoming work based on data.

💡 Pro tip: Create task templates for common project types – you'll save time on new projects!
