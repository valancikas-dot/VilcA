📊 How to Create Construction Estimate

Learn how to create professional construction estimate with Rangis app – from material list to final PDF for client.

1

Create New Project

Open Rangis app and click "New project". Enter project name (e.g., "Apartment Renovation, Oak St. 15") and address. You can also add client information.

2

Divide Into Sections

Divide project into logical sections: demolition, walls, flooring, electrical, plumbing, etc. This helps organize and present work to client.

3

Add Materials

For each section add materials: name, quantity, measurement unit, unit price. Rangis automatically calculates total amount.

4

Add Labor

Enter labor hours and hourly rate for each section. You can set different rates for different work types.

5

Set Margins

Set percentage margin for materials (e.g., 15%) and labor (e.g., 20%). Margin is calculated automatically.

6

Generate PDF

Click "Generate estimate" and get professional PDF document with all data. Send to client via email or print.

💡 Pro tip: Save common materials to templates – next time you'll create estimate 3x faster!
