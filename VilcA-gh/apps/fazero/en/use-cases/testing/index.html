⚡ How to Perform Electrical Installation Testing

Learn how to perform comprehensive electrical installation tests according to IEC 60364 standard with Fazero app.

1

Create New Installation

Open Fazero and click "New installation". Enter installation name, location, and basic information (building type, voltage system, etc.).

2

Select Required Tests

Based on installation type and requirements, select which tests to perform: visual inspection, continuity of protective conductors, insulation resistance, SELV/PELV verification, etc.

3

Perform Visual Inspection

Complete the visual inspection checklist. Document any defects or non-conformities with photos.

4

Perform Measurements

Use calibrated test instruments to perform required measurements. Enter values into the app for each circuit.

5

Review Automatic Validation

Fazero automatically checks all values against IEC 60364 requirements. Failed tests are highlighted in red.

6

Generate Test Protocol

Click "Generate Protocol" to create official PDF document with all test results and compliance confirmation.

💡 Pro tip: Create templates for common installation types – you'll complete documentation much faster on similar projects!
