✅ IEC 60364 Standards Compliance

Learn how Fazero automatically ensures your installation testing meets IEC 60364 requirements.

Supported Standards:

  • IEC 60364 – Low-voltage electrical installations (international)
  • HD 60364 – European harmonized document
  • National standards – Local implementations and amendments
  • IEC 61557 – Electrical safety in low voltage systems (test equipment)
1

Select Applicable Standard

When creating installation, select which standard applies. App will use correct limit values and test requirements.

2

Automatic Limit Values

For each measurement type, Fazero knows the required limits (e.g., minimum insulation resistance ≥1 MΩ for circuits up to 500V).

3

Real-time Validation

As you enter measurements, app instantly shows pass/fail status. No need to look up tables or calculate manually.

4

Required Tests Checklist

App ensures all required tests for the installation type are completed. Nothing is forgotten.

5

Compliance Declaration

Generated protocol includes formal compliance declaration with reference to applicable standard sections.

💡 Pro tip: Stay updated – Fazero automatically updates when standards are revised, so you're always testing to current requirements!
